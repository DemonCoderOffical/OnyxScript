# OnyxScript
![License](https://img.shields.io/badge/LICENSE-MIT-BLUE?style=for-the-badge&label=Lisense&labelColor=blue&color=blue
)

An ultra-modern, lightweight, and easy-to-use language designed for building applications quickly. Write powerful software in just 10 lines of code using clear, English-like syntax.

## 🚀 Key Features

* **Simple Syntax:** Written in normal, natural English structures.
* **Lightweight:** Runs seamlessly via a single execution module.
* **Modular Design:** Built-in modular architecture to easily extend features.
* **Rapid Development:** Build and deploy simple apps in under 10 lines.

## 📦 Getting Started

### Prerequisites
To execute OnyxScript, you need to have Python installed on your machine.
* Python 3.8 or higher

### Installation
Clone this repository directly to your workspace:
```bash
git clone https://github.com/DemonCoderOffical/OnyxScript
cd OnyxScript
OnyxScript <yourfilehere>.os
```

### Running Your First Script
1. Open the repository files.
2. Run the main interpreter file using your terminal:
```bash
python onyx.py
```

## 📝 Example Syntax

```OnyxScript
// Example OnyxScript code
#Adding the color module
ADD COLORS.
CHANGE_BTN_COLOR TO "blue"
CHANGE_BG_COLOR TO "lightgray"
#Adding the window
WINDOW("Windows name")
LABEL("Label")
BUTTON("Button")

```
